# 0.3.0 · Windows 便携版 / Windows portable edition

## 简体中文

下载 `codex-pet-accessories-0.3.0-windows-x64.zip`，完整解压后双击 **CodexPetAccessories.exe**，无需自行安装 Python。

- 适用于 Windows 10 / 11 x64。仍需已安装并登录 Codex 桌面应用，且显示宠物。
- 包含七种用量配件、左右布局、周期双色、设置菜单与可选的随宠物自动启停。
- 新增宠物与配件、实际设置面板两张展示图，使用隔离配置和虚拟数据，不使用作者的桌面截图。
- 同时提供源码 ZIP 与 `SHA256SUMS.txt`。程序只提供配件，宠物本体需另行安装。
- 启用自动启停后请保留解压文件夹的位置，移动前先关闭该开关。

[中文使用说明](https://github.com/am-q/codex-pet-accessories/blob/v0.3.0/README.md)

## English

Download `codex-pet-accessories-0.3.0-windows-x64.zip`, extract the entire ZIP, then double-click **CodexPetAccessories.exe**. A separate Python installation is not required.

- Requires Windows 10 / 11 x64 and a signed-in Codex desktop application with its pet visible.
- Includes seven usage accessory styles, split layouts, period colors, settings, and optional automatic startup with the pet.
- Two new demonstrations show the pet with accessories and the actual settings panel. They use isolated settings and synthetic data, never the author's desktop screenshots.
- A source ZIP and `SHA256SUMS.txt` are included as separate downloads. Install the pet itself separately.
- Keep the extracted folder in place while automatic startup is enabled; disable it before moving the application.

[English guide](https://github.com/am-q/codex-pet-accessories/blob/v0.3.0/README.en.md)
